# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [test@xoriant.com](mailto:test@xoriant.com).
Do not post vulnerability details, credentials, or exploit instructions in public issues, discussions, or pull requests. Include the affected project version or commit, a description of the potential impact, and steps to reproduce the issue where possible. Do not include live credentials or unnecessary personal or customer data in a report.

No response-time commitment is made by this policy.
